# AI Spark

Build a modern, responsive SaaS web app called AI Workplace Productivity Assistant.

Core Requirement

Create a frontend-focused application with no database, authentication, backend server, or persistent data storage.

All responses must be genuinely AI-generated. Do NOT use hardcoded, generic, predefined, or mock responses. Connect the app to an AI model/API supported by Lovable so user prompts produce dynamic AI responses.

Design

Modern professional SaaS dashboard

Dark/navy-blue theme

Responsive desktop, tablet and mobile design

Left sidebar navigation

Clean cards, forms, buttons and AI interfaces

Professional typography and polished UX

1. Smart Email Generator

Allow users to enter:

Recipient/context

Subject

Key points

Desired tone: Formal, Friendly, Persuasive

Use AI to generate a unique professional email based on the user's inputs.

Features:

Editable AI output

Copy button

Regenerate button

Clear loading state while AI generates

2. AI Research Assistant

Allow users to:

Enter a research topic

Paste article/text content

Paste a URL from a website or online platform

Use AI to dynamically generate:

Summary

Key Insights

Recommendations

The output must be based on the actual user-provided topic, text, or URL—not generic placeholder content.

Make results editable and copyable.

3. AI Workplace Chatbot

Create an interactive AI workplace assistant.

Users can ask any workplace-related question or provide instructions. Every response must be dynamically generated by the AI model.

Include suggested prompts as examples, but never return predefined responses.

Dashboard

Include:

Welcome section

Quick-access cards for the three AI tools

Recent session activity only while the page/session is active

Sidebar navigation

No persistent history or database

AI Experience

Show "AI is thinking..." or a similar loading indicator while generating

Handle empty inputs and API errors gracefully

Allow users to regenerate responses

Keep AI outputs editable

Use structured prompts internally so responses are relevant, professional and useful

Responsible AI

Display this disclaimer:

"AI-generated content may contain errors. Review and verify important information before using it."

Important Constraints

Every response must be AI-generated

No hardcoded AI answers

No generic/mock responses

No database

No authentication

No persistent storage

No unnecessary backend features

Keep the application lightweight to minimize Lovable credit usage

Use Lovable's supported AI integration/API approach to connect the frontend to the AI model

Do not build features outside the three core AI tools and dashboard
